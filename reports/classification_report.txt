2. FEATURE CONFIGURATIONS
------------------------------------------------------------------------
  cbow        : CBOW doc vectors (100d)  dims=100
  skipgram    : Skip-gram doc vectors (100d)  dims=100
  tfidf_word  : TF-IDF word n-grams  analyzer=word  ngram=(1, 2)  vocab=50000
  NOTE tfidf_char: Character n-grams were measured on the full training split: fitting + transforming took ~459s and produced a ~74.5M-nonzero (78806 x 100000) CSR matrix taking >1.2 GB, on a machine with 7.2 GB total RAM. Training four classifiers on top of that is not practical here, so the word-level baseline is used instead. Set enabled=True (and expect a long run) to attempt it.
